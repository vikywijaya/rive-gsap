How to set up the Rive file

Each artboard needs one state machine. The JS auto-detects inputs by type — names don't matter:

ArtboardInput type neededTriggered by
Animation ABooleanMouse hover
Animation BNumber (0–100)Scroll position
Animation CLoop state (no input)Auto-plays on load
Animation DTriggerButton click
