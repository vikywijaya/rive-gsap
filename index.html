How to set up the Rive file

Create a single state machine called Main and add these inputs:

Input nameTypeUsed for
isHoveredBooleanAnimation A — hover
scrollProgressNumber (0–100)Animation B — scroll
—Loop stateAnimation C — auto-loop
onClickTriggerAnimation D — button

Then export the file as animation.riv and place it next to index.html.
